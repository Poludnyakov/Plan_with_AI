Изменить мероприятие

Не занимает часы и может пересекаться с расписанием.

Можно добавить несколько уведомлений или удалить их все.

Импорт календаря

Файл .ics или архив .zip из Google: Google — Настройки → Импорт и экспорт → Экспорт; Яндекс — настройки календаря → Экспорт; Apple и Outlook — «Экспорт».

Google — «Закрытый адрес в формате iCal» в настройках календаря; Яндекс — ссылка из «Экспорт»; iCloud — ссылка общего календаря.

Нужен пароль приложения: Яндекс ID → Безопасность → Пароли приложений; Apple ID → Пароли приложений. Пароль используется один раз и не сохраняется. Google по паролю не подключается — используйте ссылку.

Повторяющиеся события добавятся на год вперёд, прошедшие — нет. Повторная загрузка добавит только новое; удалить импорт целиком можно в «Истории».
